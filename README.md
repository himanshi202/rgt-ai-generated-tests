# rgt-ai-generated-tests

Playwright (JS) automation scripts generated by the RGT AI Test Pilot pipeline
from approved test cases. Every script here arrives via an automatically
opened pull request, never a direct push — a human reviewer (see
`.github/CODEOWNERS`) must approve and merge before it counts as "Automated."

## Structure

```
tests/<client_id>/<ticket-key>.spec.js   one file per approved test case
```

## How scripts get here

1. A test case is approved on the RGT AI Test Pilot review page.
2. `RGT Pipeline - Automation Script Generator` (n8n) asks a Dify agent to
   draft a Playwright script from the approved test case, grounded in past
   scripts retrieved from this repo's history.
3. It opens a PR here with the draft.
4. This repo's `lint.yml` Action runs ESLint on the changed file(s) as a
   required check — syntax/lint only, scripts are never executed in CI.
5. The CODEOWNERS-assigned reviewer for that client folder reviews and
   either merges or pushes fixup commits directly on the PR branch.
6. On merge, `RGT Pipeline - Automation PR Merge Handler` (n8n) marks the
   originating test case "Automated," comments back on the original ticket,
   and feeds the merged script back into the knowledge base used for future
   generations.

## Local setup

```
npm ci
npx playwright install --with-deps chromium
npm run lint
```
